# LoopAgent

一个轻量、可修改、模型无关的 Agent Runtime。

当前版本提供 Kimi Web 适配器，可以让模型连续生成、运行和修改 Python 程序。

> ## 注意事项
>
> **LoopAgent 会直接在本机执行模型生成的 Python 代码。**
>
> 不要让不可信的模型执行不可信的任务，也不要运行来源不明的 `seed.py`。
>
> 当前版本的安全检查只能阻止少量明显的危险操作和自引用行为，**不是完整的安全沙箱**。
>
> 因此建议只在自己能够控制的环境中使用。
>
> 另外，当前 Kimi Web 适配器依赖网页界面，网站 DOM、登录状态或浏览器行为发生变化时，适配器可能失效。
>
> `attach_existing` 也是实验性功能，并不保证所有浏览器环境都可以正常连接。
>
> 如果只是正常使用本项目进行个人开发和测试，可以按照普通本地 Python 程序的方式使用。
